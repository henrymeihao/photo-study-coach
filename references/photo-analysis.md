# 摄影分析引擎 v2：从画面证据到可复现拍法

本文件是 photo-study-coach 的核心分析规范。主 SKILL.md 在完成图片读取后必须应用本规范。原帖公开展示的栏目是作品展示、构图、用光和焦段；下面的专业分析维度为本项目自行扩展，不应冒充原作者私有 Skill 的源码。

## 0. 核心原则

摄影拉片不是给照片贴风格标签，更不是假装知道原作者的拍摄过程。先识别画面中具体、可指认的证据，再解释视觉作用，最后给出一个能试拍的选择。

每项有意义的结论尽量使用四段式：

- **证据（Where / What）**：指出可见的画面位置或关系（例如「人物画面左侧的脸颊比右侧亮，鼻影向画面右下延伸」）。
- **机制（Why）**：解释摄影因素怎样产生效果（例如「斜上方的定向光建立面部体积」）。
- **复现（How）**：提出可执行的拍摄或修图动作（例如「让人物转身约四分之一圈，使窗户位于面部前侧」）。角度和距离只是试拍起点，不是反推参数。
- **验证（Check）**：观察什么信号说明成功（例如「鼻影方向稳定，近侧眼睛仍有层次，不出现突兀眼窝黑洞」）。

至少对最关键的光线和色彩结论做到四段式。普通读者先看一句核心发现；专业层级再展开。不要给每张照片机械生成八个无依据的模块；但对清晰可辨的光、色、构图，必须有实质分析。

### 证据等级

- A / 已证实：作者明确描述、可信 EXIF 或可见且毫无争议的画面事实；注明证据属于文字还是图像。
- B / 高可信解释：多个画面证据共同支持的机制，仍使用「更可能」「看起来」等谨慎措辞。
- C / 备选假设：证据不足或多个方案能生成相似成片；列出 A/B 方案与区分办法。
- D / 不可判断：原图缺失、压缩严重、阴影不清或不同原因无法区分，明确跳过。

不能从成片确定灯具型号、灯数、是否使用闪光、准确色温、光比 EV、实际焦段/光圈/快门/ISO、镜头品牌、修图滑块、布光距离。建议的试拍值必须单列为「起点建议」。

## 1. 先做 30 秒视觉诊断

1. 主体是什么？眼睛第一眼落在哪里，第二眼移到哪里？以明度、色彩、清晰度、面孔/目光、线条中的哪些因素为证据。
2. 最鲜明的两个可复用决定是什么？如「让主体处在亮区」「让背景色相集中」「在前景加遮挡」，不是「高级」「氛围感」。
3. 这张照片主要靠什么成立？在人像、风光、街拍、静物之间确定本次两到三项最值得深挖的维度。
4. 哪些地方仅凭图无法判断？提前标注不确定性，避免后续越写越确定。

## 2. 构图与空间：分析结构，不是套公式

必须检查：
- 画幅比例、主体位置/占画面面积、视觉重心与负空间是否平衡。
- 前中后景的深度关系；重叠、遮挡、大小透视、空气透视如何建立层次。
- 主体边缘与背景的分离：轮廓重叠、切头、地平线穿过头部、杂物、亮斑竞争。
- 线条和视线如何移动：引导线、框中框、对称/失衡、重复与节奏、目光方向。
- 机位线索：相机高低、是否仰俯拍、水平线和建筑收敛；只给合理的相对判断。
- 是否存在近大远小、背景压缩、倾斜透视；区别镜头视角、拍摄距离和裁切对视觉效果的影响。

输出应包含「为什么这样构图有效」「如果移动一个机位会怎样」，而不是只说「三分构图」或「中心构图」。

## 3. 用光与布光：核心高优先级维度

### 3.1 先读画面，再猜光源

沿以下顺序取证：

1. **亮度地图**：主体、背景、前景哪一块最亮？暗部落在哪里？高光是否聚集于脸、衣服、边缘或地面？
2. **方向**：鼻影/下巴影/投影、脸部明暗交界、建筑或地物阴影、头发轮廓、眼神光，是否支持正面光、侧光、侧逆光、逆光、顶光、底光？把「画面左/右」和「人物左/右」明确区分。
3. **光质**：阴影边缘陡峭还是过渡宽？皮肤高光窄而尖锐还是宽而柔和？据此讨论硬光/软光及有效光源相对大小；不要把「柔和色彩」误当「柔光」。
4. **光强与光比**：主体亮暗两侧的反差、阴影保留的纹理、背景亮度与面部亮度关系。默认使用低/中/高反差等定性词；未经测量不写「1:4」「两档」。
5. **光源结构**：哪些证据支持主光（key）、填充（fill）、轮廓/逆光（rim）、背景光（background）、可见实景灯（practical）？若只见单一连续自然光，禁止为了画一张复杂图而编出三灯布光。
6. **环境影响**：天光、窗口、墙面反射、地面反射、树荫、色彩反射、混合光如何改变阴影、色温和轮廓。
7. **控制方式**：遮光/负补光、反光板、换朝向、靠近窗户、改变拍摄时机，比「买灯」更优先。

### 3.2 布光推理与假设

说明：
- 证据：光向、投影边缘、眼神光、亮暗关系中至少两个可见线索（若实际只有一个，不要虚构第二个）。
- 最可能的方案 A：相机、主体、背景相对位置；光线来自画面哪侧、相对高低；室内/室外条件。
- 替代方案 B：自然光与人造光、光源 vs 反光、现场光 vs 局部后期，都可能构成相似成片时给出替代解释。
- 验证：让用户实拍哪两个变量、怎样判断哪套解释更像目标。

### 3.3 布光示意图的硬性要求

有足够画面证据且输出图解时，绘制俯视图；涉及高度、鼻影、头发轮廓时加侧视或文字说明。必须标注相机、主体朝向、背景、已见的实景光源、假设的光源及箭头；所有假设光源使用虚线并标「推测」。示意图方向应与所展示的参考图一致，并写清「画面左侧」与人物自身左右方向。不应把推测画成事实。存在两个相当可能的方案时并列画 A/B，或只展示不确定性较小的复拍方案。

## 4. 色彩：区分色相、明度、饱和度和色光

### 4.1 不可跳过的五层观察

1. **色彩地图**：背景、皮肤/主体、衣物/道具、高光/阴影分别是什么色相、偏色和饱和度？用画面位置定位，不能仅说「整体青橙」。
2. **主辅强调色**：主色覆盖什么区域、辅助色维持什么统一感、少量强调色为什么吸引眼睛；区分面积大与视觉权重大。相邻色、互补色、冷暖对比、同色系是否真正成立？
3. **明度层级**：主体与背景靠亮度分离，还是靠色相/饱和度分离？建议用黑白预览验证；如果转黑白后主体仍清晰，往往说明明度组织有作用。
4. **冷暖来源**：是场景固有色、不同色温光源、白平衡，还是后期色彩分级？仅能辨识成片，不要反推唯一的原因。特别关注暖肤色与冷背景、冷阴影与暖高光、偏色的中性物体。
5. **肤色与中性色**：人像检查脸颊、额头、颈部相对自然与否、有没有绿偏/洋红偏、背景反射污染，是否为表达性调色而非失误。不要强迫所有作品肤色都「自然」。

### 4.2 色调及后期分析

另外分析：动态范围感、黑位/白位、层次、整体反差与局部反差、色彩纯度、暗部是否压死、高光是否失纹理、颗粒/光晕/清晰度是否可见。

输出时分开写：
- **成片所见**：哪些区域呈现什么色相、亮度、饱和度，形成什么视觉层次。
- **可能过程**：现场色光/白平衡/局部遮罩/色彩分级可能共同贡献；说明不可区分项。
- **仿拍/调色起点**：先保证现场背景、衣物及光线，再调曝光与白平衡，再做局部明度，最后微调 HSL 与色彩分级。允许推荐操作方向，但未经原片对比不写精确 Lightroom 数值。

### 4.3 统计仅是辅助

只有真正读到像素并完成统计，才可展示色卡、直方图或颜色占比；应注明采样图、色彩空间、采样区域与算法。未经统计不做百分比。色块不能代替讨论主色在哪、为什么有效、如何现场实现。屏幕截图/含白边/网页 UI 的像素不得混入统计。

## 5. 镜头、距离与景深

- 明确区分**透视**主要随机位和距离变化、**画面视角**受焦距/画幅/裁切影响；不要简单说长焦必然压缩透视。
- 判断背景相对大小、前后景比例、边缘拉伸、焦外成像、背景虚化，不把「虚化大」直接等于「大光圈」。
- 原图参数存在时引用原参数；不存在时给实拍焦段/画幅等效范围作为探索起点，例如从标准视角开始试，再通过保持主体大小改变距离比对背景。参数不是原作者的事实。
- 对手机、APS-C、全画幅方案可按用户设备给等效视角；没有器材信息可给跨设备的视觉目标，不强迫猜相机。

## 6. 时间、动作与叙事

- 人像：眼神方向、姿态/手部、人物与环境的互动、服装与背景分离、面部阴影风险。
- 风光：光线出现的时机、天气/雾气/云影、地形与图层、天空与地面明度。
- 街拍：人物进入光区或几何框架的决定性时刻、动态关系、等待策略。
- 静物：形状/质感与反光控制、背景与道具颜色、光泽边缘。

指出本张照片是否更依赖「等一个时机」而非更换设备；不能凭画面断言作者意图。

## 7. 从照片反推「最小可执行复拍方案」

对每张重点图给一段现场动作，而不只是理论：

- 场地/天气/时间：必要条件是什么；不可控时的替代方案是什么。
- 相机—主体—背景：谁先站哪、朝哪、相机高低/距离调整顺序；无尺标不编具体米数。
- 光：要找的阴影方向和软硬；主光/补光控制动作；A/B 假设如何用实拍测试。
- 色：优先选什么背景/服装/环境色；后期只负责哪些局部修正。
- 镜头：用户已有器材可采用的焦段或裁切起点，注明建议。
- 成功标准：拍完看哪些具体细节；下一轮只改一两个关键变量。

理想格式：
「先把人放在比背景更亮的位置，观察脸上是否出现从画面右上到左下的亮暗过渡；如果阴影过硬，让主体进入建筑阴影或转向更大的漫射光源；背景仍太亮则换角度，而不是只靠压暗后期。」

## 8. 建议交付结构

### 简读卡（照片旁边，不超过 150 中文字）
- 这一张为什么好看：一句机制判断
- 决定画面的 2–3 个关键选择
- 我能立刻试的 1 个动作

### 深度拆解（按证据强弱选择小节）
- A. 构图与机位：画面证据 → 视觉效果 → 移动机位对照
- B. 用光与布光：光向、光质、光比、环境反射；最多两套可靠假设，示意图
- C. 色彩与影调：主色及空间分布、色相/明度/饱和度关系、冷暖来源、肤色/中性色、调色起点
- D. 镜头与景深：可见透视/焦外依据、未知参数、试拍视角
- E. 人物动作/时间与叙事：只在有价值时展开
- F. 现场复现卡：步骤、替代条件、验证指标
- G. 来源、证据等级、不确定性和作者原话（如有）

### 一组照片的综合页
- 找出跨图重复的「视觉规则」（例如背景总比脸暗、重复使用低饱和背景、相似景别），每个规则至少举两张照片的证据。
- 区分有证据的风格共性和偶然的单张效果。
- 给一个迁移练习：使用用户自己的城市/人像/旅行场景也能实现的选择，不要求相同器材。

## 9. 防止空话的自检

输出前逐项自检：
1. 如果删掉照片，这段话还适用于一百张其他照片吗？如果是，必须补画面位置与具体机制。
2. 用光部分是否区分了**光向、光质、反差、光源角色**？证据不足的维度是否明确跳过？
3. 色彩部分是否区分**色相、明度、饱和度**，并明确这些关系分别在主体、背景、阴影的哪里？
4. 是否把**已知拍摄信息**与**推测的复拍方案**严格分开？
5. 是否解释了**为什么有效**和**我怎么做**，而不只有风格形容词？
6. 布光图是否存在无证据的三灯架构？箭头方向、画面左右是否自洽？
7. 有没有假百分比、假参数、未计算却展示的色卡、把调色起点写成作者预设等问题？
8. 如果图片看不到，是否停止了照片级分析，而不是从标题和想象继续生成？
