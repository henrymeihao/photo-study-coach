# 摄影分析方法

SKILL.md 的核心规则优先。本文件说明怎样从画面证据选出主技巧和对照，以及各维度看什么。只读与主技巧有关的章节。

## 1. 诊断步骤

1. **确认目标**：用户说过的意图优先；没说就写“这张似乎想突出……”。
2. **记录观看顺序**：第一眼看哪、第二眼看哪？是哪个位置的形状、明暗、颜色、动作或空间关系造成的？
3. **列 2–3 个候选**：每个都写成拍摄决定，例如“低机位贴近水面放大倒影”“等人物走进亮区”“用前景遮挡做框”。
4. **选一个主技巧**，依次看：画面证据是否具体；去掉它照片效果是否明显变差；是否符合目标；学习者能否在别处复用和验证。证据势均力敌时写出取舍理由；证据不足时直接说选不出。
5. **设计一个对照**：选最能检验主技巧的那个变量。

每条关键结论按四段写：

- 证据：画面位置和关系，例如“人物画面左侧脸颊更亮，鼻影向画面右下延伸”。
- 机制：为什么产生这个效果，例如“斜上方的定向光让面部有立体感”。
- 做法：下次怎么拍，例如“让人物转身约四分之一圈，让窗户在脸的前侧”。角度和距离是起点，不是反推的参数。
- 检查：成功的信号，例如“鼻影方向稳定，靠近相机那只眼睛仍有细节”。

## 2. 单变量对照怎么写

对照回答“如果只改一个决定，画面可能怎样变”，用来训练判断，不代表摄影师拍过这个版本。

- **固定**：写出保持不变的条件，如位置、焦距、人物站位。
- **只改**：一个可控变量，如相机高度、人物朝向、背景亮度、等待时机。同时换焦段和位置不算单变量。
- **预期**：哪个区域、怎样变，用“可能”“预期”。
- **得失**：同时写收益和代价。“不同”不等于“更差”，按表达目标评价。
- **验证**：同地点拍 A/B 两张，比较哪 1–2 个可见指标。天气或瞬间不可控时用近似条件，并说明限制。

示例（通用教学示例，不针对任何未见照片）：主技巧“低机位利用水洼倒影”。固定位置和朝向，只把相机从贴近水面升到胸口高度。预期倒影在画面下部占比下降，建筑和地面信息增加。得到环境交代，失去镜像结构的冲击力。拍低、高两张，比较倒影面积和第一眼落点。

没有足够画面或物理依据时，只写成探索性假设。不生成替代照片冒充对照结果；需要示意时用简单 SVG，标“教学示意，非真实重拍”。

## 3. 构图与空间

按需检查，只输出与主技巧有关的项：

- 主体位置与面积、视觉重心、留白是否平衡。
- 前中后景：重叠、遮挡、近大远小、空气透视怎样建立层次。
- 主体与背景分离：轮廓重叠、地平线穿头、杂物、亮斑抢眼。
- 视线路径：引导线、框中框、对称或失衡、重复节奏、人物目光。
- 机位线索：相机高低、仰拍俯拍、水平线、建筑线条汇聚，只做相对判断。
- 透视主要由拍摄距离决定，视角由焦距、画幅和裁切决定；不简单说“长焦压缩”。
- 消失点只随相机朝向变化。相机朝向不变、只横移或升降时，平行线（路、轨道、走廊）的消失点在画面里的位置不变；变化的是近处物体的大小和线条从哪里进入画面。转动相机才会让消失点移动。写对照的“预期变化”时按这条推理。

写“为什么这样有效”和“移动一次机位会怎样”，不只写“三分构图”。

## 4. 用光

先读画面，再猜光源：

1. **亮度分布**：主体、背景、前景哪里最亮，暗部在哪，高光落在脸、衣服、边缘还是地面。
2. **方向**：鼻影、下巴影、投影、明暗交界、头发轮廓、眼神光支持哪种方向。分清“画面左/右”和“人物自己的左/右”。
3. **软硬**：阴影边缘陡还是过渡宽，高光窄还是宽。不要把“颜色柔和”当成“柔光”。
4. **反差**：只用低、中、高反差等定性词；没测量不写“1:4”或“两档”。
5. **光源角色**：哪些证据支持主光、补光、轮廓光、背景光、画内实景灯。只见到一个自然光源时，不编三灯布光。
6. **环境影响**：天光、窗户、墙面和地面反射、树荫、混合光怎样改变阴影和颜色。
7. **控制手段**：先考虑换朝向、靠近窗户、遮光、反光板、换时间，再考虑买灯。

推测光源时写最可能方案 A、替代方案 B 和区分两者的实拍办法。至少要有两个可见线索才写 B 级；只有一个线索就是 C 级。

画布光俯视图时：标相机、主体朝向、背景、可见光源和推测光源；推测光源用虚线并标“推测”；方向与参考图一致。两个方案同样可能时并排画 A/B，或只给复拍方案。

## 5. 色彩与明暗

1. **色彩分布**：背景、主体、衣物、高光、阴影分别是什么色相、偏色和饱和度，用位置描述，不只说“青橙”。
2. **主色、辅助色、强调色**：面积大不等于视觉权重大，少量强调色为什么抢眼。
3. **明度层级**：主体靠亮度还是靠颜色和背景分开？转黑白后主体仍清楚，说明明度在起作用。
4. **冷暖来源**：可能来自场景本身、不同色温的光、白平衡或后期，成片通常无法区分，写出可能的组合。
5. **肤色**：看脸颊、额头、脖子是否偏绿或偏洋红、是否被环境色染色；表达性调色不算错误。

后期只写方向和顺序：先现场选背景、服装和光线，再调曝光和白平衡，再做局部明暗，最后微调颜色。不写精确的修图数值或“某某预设”。

百分比、色卡、直方图只有在你实际读取像素并计算过时才写，并注明统计区域、色彩空间和方法；截图里的网页、白边、文字不能算进去。没有计算就用定性描述。

## 6. 镜头、距离与景深

- 有原图参数时引用并标来源；没有时只给“起点建议”，按手机、APS-C、全画幅分别写等效视角，设备未知就写视觉目标。
- 背景虚化受光圈、焦距、对焦距离和背景距离共同影响，不把“虚化大”等同于“大光圈”。
- 保持主体大小不变、改变拍摄距离，是比较透视最直接的练习。

## 7. 时机与题材

- 人像：眼神方向、姿态和手、人与环境的互动、服装与背景分离、面部阴影。
- 风光：光线出现的时机、天气、雾、云影、地形层次、天空与地面明度。
- 街拍：人物进入光区或几何框架的瞬间，等待和预判。
- 静物：形状质感、反光控制、背景和道具颜色。

说明这张更依赖“等一个时机”还是“换一个位置”，不凭画面断言作者意图。

## 8. 一组照片的综合

- 找跨图重复的规律，如“背景总比脸暗”，每条至少用两张图的证据。
- 区分有证据的共性和单张偶然效果。
- 给一个用户在自己城市、人像或旅行中能做的迁移练习。

## 9. 输出前自检

1. 删掉照片，这段话还适用于一百张别的照片吗？是就补位置和机制。
2. 首屏是否只突出一个有证据、可复用的主技巧？
3. 对照是否只改了一个变量，写了得失和验证方法，并标为预测？
4. 已知信息和推测是否分开？有没有假参数、假百分比、无证据的三灯布光？
5. 展开用光时，是否分开写了方向、软硬、反差、光源角色？展开色彩时，是否分开写了色相、明度、饱和度及其位置？
6. 布光图的箭头方向和画面左右是否一致？
7. 看不到图时，是否停止了照片级分析？
8. 学习者不看深度部分，能否知道现场先看什么、改什么、怎么检查？
9. 换场景用法是否写了不适用情况？
