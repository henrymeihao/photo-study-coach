# HTML 视觉设计系统

版本：v1  
适用范围：Photo Study Coach 默认离线 HTML 学习卡。  
目标：让每张卡片的照片和分析内容不同，但阅读体验、视觉层级与交互保持稳定。

## 1. 设计方向

**Editorial photography journal（摄影编辑部 / 视觉学习杂志）**。

关键词：克制、温暖、清晰、图像优先、编辑式排版。页面不是 SaaS Dashboard，不是数据报表，也不是花哨的作品集落地页。照片是主体，文字负责解释照片为什么有效，以及下一次拍摄能做什么。

## 2. 设计 token

模板是 token 的唯一实现来源。新增组件只能复用以下变量，不得在单次输出里发明新主题。

| Token | 值 | 用途 |
|---|---|---|
| `--paper` | `#F4F3ED` | 页面暖白背景 |
| `--surface` | `#FBFAF6` | 图片说明、内容卡片 |
| `--ink` | `#26362D` | 主文字 |
| `--muted` | `#68746C` | 次级说明 |
| `--line` | `#DDE2D9` | 分隔线 |
| `--accent` | `#566D5B` | 主强调色 |
| `--accent-soft` | `#E8ECE5` | 柔和底色 |
| `--highlight` | `#D7B978` | 少量标注编号/焦点 |

颜色用途要克制：强调色用于小标题、编号和交互状态；高亮色只用于照片标注焦点。不要给每个栏目分配不同颜色。

## 3. 字体与排版

- 正文使用系统无衬线字体：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif`。
- 主标题可用衬线字体：`Iowan Old Style, "Songti SC", "Noto Serif CJK SC", Georgia, serif`；字体不可远程加载。
- 页面标题桌面端约 34–46px，移动端约 29–34px；正文 14–16px；辅助信息 11–13px。
- 正文行高 1.65–1.8；每段控制在 2–4 句。不要用大段加粗制造层级。
- 标题、正文、辅助说明最多形成 3 层明显字号层级。

## 4. 页面布局

- 页面最大宽度约 1440px，居中；桌面端左右留白约 32–48px。
- 页头先显示小型品牌标识、标题和一句副标题，不放导航栏、侧栏或无关品牌故事。
- 主体桌面端采用两栏：左侧原图/观察，右侧分析/复刻；图片列略宽或与分析列接近。
- 原图保持自然比例，不用固定高度裁切，不用背景图代替真实 img。
- 图片列可在桌面端 sticky；进入窄屏后取消 sticky。
- 窄屏（约 900px 以下）改为单列，先照片、后分析；左右内边距约 18–22px，不得横向滚动。
- 页面底部只保留一次来源和验证状态，不重复显示来源。

## 5. 内容组件

### 核心判断
- 使用一个主标题和一段解释。
- 只强调一个主技巧；候选技巧放在深度区或省略。
- 不使用评分徽章、星级、百分比或“专业度分数”。

### 分析卡
- 通常 2–4 张，按实际相关维度选择。
- 每张卡遵循“画面证据 → 视觉机制 → 为什么有效”，不堆摄影术语。
- 使用统一的细分隔线、编号和标题；不为不同维度设置不同卡片颜色。

### 三要素复刻卡
- 光线、构图、色彩三项保持同一视觉组件。
- 每项包括寻找条件/安排动作/检查信号；检查信号以次级文本呈现。
- 不加入器材购买建议作为默认步骤。

### 深度分析
- 使用原生 `<details>/<summary>` 折叠。
- 默认关闭；只放真正有价值的证据、替代解释、参数来源、迁移或局限。
- 不把首屏已讲过的内容原样复制到折叠区。

### 照片标注
- SVG 叠加在原图上，默认隐藏；通过一个明确按钮切换。
- 颜色以浅金色/暖白色为主，线条细、数量少，避免遮挡主体。
- 编号必须和图例一一对应；标注只圈出真正支持判断的区域。SVG 坐标使用原图像素，线宽、编号半径和字号按原图长边比例计算，保证不同尺寸图片上的视觉权重一致。
- 不画未经验证的光线箭头、灯位、机位或几何边界；推测必须用虚线并标明“推测”。
- 不用模糊光晕、渐变滤镜或装饰性箭头制造“分析感”。

## 6. 交互与可访问性

只允许真实有用的轻交互：
- 原图/标注切换（有标注时才出现）。
- 原生折叠区。
- 浏览器打印。

按钮必须有可见名称、键盘焦点样式和正确的 `aria-pressed` 状态。图片有准确的 `alt`。SVG 叠加层使用 `aria-label`，不截获鼠标事件。不要使用没有后端的上传、AI 点评、保存、登录或同步按钮。

## 7. 打印与离线

- CSS、JS、SVG、图像全部内嵌；禁止 CDN、外部字体、远程图片、在线 API、第三方脚本。
- 打印时隐藏交互控件、取消 sticky、展开深度内容；避免图片、卡片和步骤在页面中间被切断。
- 不强制背景色打印；即使浏览器关闭背景图形，文字层级也应清楚。
- 单文件应可在断网状态下打开。

## 8. 禁止事项

- 每次输出另起一套颜色、字体、圆角、阴影或布局。
- 大面积彩色卡片、渐变、玻璃拟态、仪表盘式 KPI 或装饰性徽章。
- 为填充页面重复同一结论或强行补齐无关分析维度。
- 裁切、重绘、生成或替换用户原图。
- 把推测性标注伪装成测量结果。
