# 视觉学习卡格式

默认交付由离线 HTML 学习卡和 Markdown 档案组成。用户明确只要文字或其他格式时，遵循用户指定格式。两种交付的核心判断必须一致。

## 信息架构

### 01 · 原图观察
- 展示原始照片，保留原比例。
- 用 SVG overlay 标记本次分析相关区域：面部受光区、前景遮挡、视觉中心、背景亮部、色彩呼应等。
- 标注必须根据实际照片定位，不得使用通用占位坐标冒充准确标注。
- 提供原图/标注切换；原始图像像素不变。

### 02 · 核心判断
一句话概括最值得学习的拍摄决定，避免用“三分构图”“电影感”“高级感”等标签代替决定。

### 03 · 为什么好看
根据照片选择相关维度，解释画面证据、视觉机制和审美效果：
- **光影**：亮部落点、方向、软硬、反差、主体与背景分离。
- **构图与空间**：景别、机位、前中后景、遮挡、透视、视觉路径。
- **色彩**：主色、辅助色、强调色，色相/明度/饱和度、冷暖和肤色。
- **人物表现**：眼神、姿态、手势、服装和环境互动。
- **时机与叙事**：等待的瞬间、人物与环境的关系。

不要机械地把每个维度写成长段落。只保留能解释照片效果的内容，指出核心因素与辅助因素。

### 04 · 三要素复刻
**光线**：去哪里找、主体如何安排、怎样控制亮区/暗区、检查面部或主体细节/阴影边界/高光。
**构图**：相机、主体、前景、背景如何安排；哪些元素保留或避开；检查视觉中心、层次和主体分离。
**色彩**：如何选择背景、服装、道具或环境色；主色与呼应色如何分布；如何避免颜色互相争抢。后期只提供方向，不虚构数值。

建议给清晰现场顺序，如“先找光 → 再组织构图 → 最后统一色彩 → 安排人物动作”，但按题材调整，不强制套用。

### 05 · 镜头与参数
**镜头语言（优先）**：景别、视角观感、透视关系、拍摄距离、前景/主体/背景距离、景深与虚化及其他可能成因。

**参数证据（谨慎）**：
- EXIF 存在：展示实际读取字段，标记“原文件 EXIF”。
- 作者原文存在：引用来源，标记“作者说明”。
- 没有证据：具体参数写“无法确定”，不填貌似精确的数字。
- 有合理推测：列出画面依据、置信度、替代解释，并标记“推测”。
- ISO、快门、光圈、焦段和器材型号不得仅凭画面臆造。
- 复刻参数与作者原始参数分栏，练习值标“起点建议”。

### 06 · 证据与进阶分析
默认折叠：关键判断的画面证据、推测及替代解释、无法判断的内容、EXIF/作者原文来源和补充技术信息。

## HTML 交付要求
- 单个离线 HTML 文件，图片内嵌，CSS/JS/SVG 内嵌，不依赖外部 URL。
- 桌面端照片与分析并列；窄屏上下排列；照片保持原始比例。
- 原图/标注切换；标注按原始图片比例定位。
- 不用 AI 生图重绘原图；不生成虚假 A/B 对照照片；教学示意明确标记“示意”。
- 不放没有真实后端支持的上传、AI 点评或保存按钮。
- 深度分析默认折叠；页面优先呈现视觉结论和复刻方法。
- 提供打印样式；实际打开检查图片、标注、折叠和桌面/窄屏布局后才能声称验证通过。

## Markdown 档案模板
```markdown
# 摄影学习卡：{一句话核心技巧}
## 原图观察
{三项以上可核对的画面元素与位置}
## 为什么好看
- 光影：{证据 → 机制 → 效果}
- 构图与空间：{证据 → 机制 → 效果}
- 色彩：{证据 → 机制 → 效果}
- 人物表现/时机：{仅在相关时填写}
## 三要素复刻
### 光线
{寻找条件、现场动作、检查信号}
### 构图
{相机/主体/前景/背景关系、现场动作、检查信号}
### 色彩
{环境/服装/道具选择、色彩组织、检查信号}
## 镜头与参数
- 镜头语言：{视角、透视、距离、景深的可见表现}
- EXIF/作者资料：{真实字段与来源；缺失则说明}
- 推测：{依据、置信度、替代解释；没有则写无法确定}
## 证据与局限
{事实、解释、推测和未知}
## 来源
{原图来源、作者、链接、EXIF 来源}
```
