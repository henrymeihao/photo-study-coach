# 学习手册版式

按素材规模选择页面数量，不机械地每张照片生成相同页数。**每张重点照片的首屏必须突出唯一主技巧，并紧跟一个“只改一处会怎样”的反事实对照**；其它构图、用光和色彩深读放在后面，不得平均分配首屏权重。可参考以下顺序：

1. 来源与图组总览：作者、原帖链接、照片编号与联系表，本次重点学习的问题。
2. **主技巧与反事实卡（优先）**：大幅原图 + 一项关键拍摄决策及定位证据；旁栏用“保持什么 → 改一处 → 预期变化 → 收益/代价 → 怎样拍 A/B”解释，预测标记为“假设”。
3. 深度代表作拆解：按主技巧的需要选择构图标注、机位/用光俯视示意及必要的侧视图，区分相机、主体、背景、可见光源与假设光源。箭头标清“光线方向”或“拍摄方向”，不混用。
4. 色彩/明暗：有实际计算才加入统计图；每张图表附一句它对拍摄判断的帮助。解释不足的装饰图可省略。
5. 若任务包含学习：一页实拍练习与复盘记录。纯分析手册不强制附练习。

白底或浅米色、深灰文字、单一强调色。照片保持比例；优先把照片和对应解释放在同一页。中文正文须可阅读，不能为了塞进固定模板缩成小字。长段拆页，禁止文字越界、图片拉伸、标注遮脸和页脚压正文。

页脚保留作者、来源索引与页码。每个推测图旁直接标明“推测示意”，不要只在最后一页统一免责。已知参数与建议试拍参数分开。

交付 PDF 前渲染检查：代表图能看清、字体可用、标注对齐、图表与分析指同一张图、所有页面没有溢出。提供 PDF 和可编辑来源。生成失败时交付已完成的 Markdown 并如实报告，不用改扩展名冒充 PDF。
