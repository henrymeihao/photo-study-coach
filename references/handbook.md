# 三分钟摄影学习手册

默认离线单文件 HTML + 可编辑 Markdown；用户指定纯文字或其他格式时遵从。图片内嵌、不用 CDN，保留干净参考图、原图放大和按主题切换的 SVG 标注。

## 默认信息层级

1. **速学卡（展开）**：原图 + 一句主技巧 + 一处可见证据与作用 + 现场“先观察/再决定/然后调整/最后检查”四步 + 单变量反事实得失 + 一个A/B练习及1–2个验收指标。正文约300–500中文字，读完能拍；三分钟是设计目标，未测量不声称已达成。桌面图文并排，手机顺序堆叠自然滚动，不靠小字硬塞首屏。
2. **换个场景（简短展开）**：1–2个迁移例子，分别写动作、适用条件、不适用边界。不必为每个例子找照片。
3. **练习与回传（展开的短入口）**：给可复制的回传说明；更细步骤按需折叠。离线页面默认不放假上传按钮、假AI点评或假保存成功。若提供本地文本填写功能，明确保存范围并实际实现、验证，否则用Markdown记录即可。
4. **深度拆解（默认关闭）**：使用语义化 `<details><summary>`，只收录与主技巧有关的构图、用光、色彩、景深等。用户要求全面分析时才扩展，不为凑栏目填充内容。
5. **来源与技术附录（默认关闭）**：EXIF、来源、证据等级、完整推断。照片编号/署名可在原图旁用短行保留；“推测/教学示意”等直接影响理解的提示留在图旁。

Markdown采用相同顺序，短卡在前，深度附录在后，支持时也用details折叠；不能因Markdown而恢复默认长报告。

## 可选 A/B 视觉解释

用确定性SVG或绘图展示机位、人物、背景相对关系。空间/光向难以靠短句说明时优先使用；不能帮助决策则省略。两个面板固定相机和背景等保持项，只让唯一变量变化；附“教学示意，非真实重拍或透视仿真”。光源不确定用虚线并标推测；相机方向与光线方向分别标。保留原图，不生成替代照片冒充真实对照。

## 样式与验证

浅色底、深灰文字、单一强调色；照片不裁切拉伸，SVG以归一化坐标覆盖；少量标注不遮脸。正文可读，避免首屏解释重复、装饰色卡和术语堆积。

交付前实际打开**最终版本**：宽屏和窄屏检查图片比例、正文溢出、标注开关、原图放大、深度分析默认关闭且可展开、示意图、回传说明。每次修改后重查受影响内容，不把旧截图当新版本验收。不支持的检查明确列出；结构校验不能冒充视觉或学习效果验证。
