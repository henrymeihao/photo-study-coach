# 评测：输出是否稳定

改动 SKILL.md 或 references 之后，用同一批照片重跑，比较改动前后的结果。全部手工完成，不需要脚本。

## 准备照片

准备 10–15 张自己拍的或 CC0 授权的照片，不要用别人的作品。每类至少一张：

| 类型 | 对应用例 |
| --- | --- |
| 窗光人像，脸上明暗清楚 | T1 |
| 阴天户外人像，阴影不清 | T2 |
| 城市夜景，暖色招牌和冷色环境混合 | T3 |
| 有层次和雾气的风光 | T4 |
| 带网页界面的截图 | T6 |
| 水洼倒影，同时有冷暖色和引导线 | T8、T9 |
| 人很多的街拍，意图是表现人群 | T10 |
| 自己拍得不太满意的一张 | T18 |
| 一组 A/B 练习照，B 还偷偷换了焦距 | T15 |

另外准备两个无图输入：只有标题的作品链接（T5），以及在不支持图片的模型上发一张图（T17）。

照片清单和每张的拍摄意图写在本地，不提交到公开仓库。

## 怎样跑

1. 每张照片用同一句话调用技能，例如“用 photo-study-coach 拆解这张照片”。
2. 每张在每个模型上跑 3 次，每次新开会话。至少包含一个能力较弱或较便宜的看图模型。
3. 把每次输出原样存下来，文件名写清照片、模型和第几次。

## 怎样打分

每次输出逐项判断“是 / 否”：

1. 栏目和顺序与 card-format.md 模板一致。
2. 主技巧是一个拍摄决定，不是风格标签。
3. 画面证据指向具体位置，能在照片上找到。
4. “只改”只有一个变量。
5. 没有未注明来源的焦段、光圈、快门、ISO、光比、色温、品牌或修图数值。
6. 速学部分在 300–500 字左右。
7. 符合对应用例的“期望”，没有触发“失败”。

再看稳定性：同一张照片 3 次选出的主技巧是不是同一个决定？不同模型之间差多少？
